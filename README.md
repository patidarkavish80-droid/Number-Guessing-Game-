# Number Guessing Game 🎮

A simple console-based number guessing game built using Java.

## About the Project
In this game, the computer generates a random number between 1 and 100, and the player tries to guess it.

## Features
- Random number generation
- User input using Scanner
- Hints for guesses that are too high or too low
- Tracks the number of attempts
- Displays a winning message when the correct number is guessed

## Technologies Used
- Java
- IntelliJ IDEA
- Git and GitHub

## How to Run
1. Clone or download this repository.
2. Open the project in IntelliJ IDEA.
3. Run the `NumberGuessingGame` Java class.
4. Follow the instructions displayed in the console.
